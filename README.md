# 荣光之影 · 牌桌

《In the Shadow of Glory 荣光之影》双人书信游戏的**离线辅助工具**。抽牌、查表、记角色卡、写信、导出、打印，全部在一个 HTML 文件里完成。不联网，不上传，双击即开。

原作 Jessie Lee & Brandon Lee，CC BY 4.0。本工具与中文表格译文同样以 CC BY 4.0 发布。

---

## 文件

| 文件 | 用途 |
| --- | --- |
| `荣光之影-牌桌.html` | 主程序。单文件，离线可用，双击用浏览器打开 |
| `荣光之影-扑克牌面-可打印.pdf` | 54 张牌面，A4 每页 9 张（63×88mm），剪开即用 |
| `荣光之影-牌背-可打印.pdf` | 牌背，双面打印时印在背面 |
| `荣光之影-速查卡-可打印.pdf` | 13 张速查卡，每张汇总同一点数在所有表里的条目，抽牌后不必翻书 |

PDF 也可以在程序内的「牌与打印」页随时重新生成。

## 怎么用

**两人各开一份。** 每人一副自己的牌堆、一张自己的角色卡；只有信件在两人之间传递。远程游玩时这一点很重要——牌堆用尽是退场条件之一，不能共用。

1. **开局** — 翻牌确立世界前提与超能力运作方式，商定写信格式与长度，翻牌确立你们的关系。开始前先把不希望出现的话题说清楚。
2. **角色** — 抽 8 张手牌，逐项指派：超能力、掩护身份、据点、关键人物、日常目标、超能力目标、隐藏情感。指派时会显示每张手牌对应的条目，点哪张用哪张。填名字、描述彼此留下的伤痕，最后翻一张牌决定谁是英雄、谁是反派，然后「完成创建，洗牌开始」。
3. **本周** — 收到对方来信后走四步：定情绪、抽日常事件、抽超能力事件、推进一个目标。同一点数再次抽到时程序会自动往下读一条提示，不用自己记到第几条了。提示里的机制效果（获得伤痕、风险值 ±1、失去关键人物……）做成了按钮，点一下就落到角色卡上。
4. **写信** — 选信纸、写正文，可以抽「话题引子」开头。右侧实时预览，支持打印/PDF、PNG 图片、单文件 HTML、纯文本四种导出。写完「存入信箱」。
5. **信箱** — 寄出的信与贴进来的来信、每周的周志都在这里，导出后就是这一局完整的故事。

「查表」页有全部表格，「牌与打印」页可以随手抽任意一张表。

## 存档

进度存在**这台设备的浏览器本地存储**里，关掉页面不会丢。但换设备、换浏览器、清理缓存就没了——在「规则与存档」页用「导出存档文件」存成 `.json`，随时可以导回来。

少数浏览器（隐私模式、部分手机浏览器直接打开本地文件时）会禁用本地存储。这种情况下程序顶部会提示，本局只存在内存里，记得随时导出。

程序不联网、不加载任何外部资源、不收集任何数据。

## 打印建议

在浏览器打印对话框里：纸张 A4、页边距设为「无」或最小、**关掉页眉页脚**、**打开「背景图形」**。牌面用 200g 左右的卡纸效果最好；也可以印在普通纸上塑封。

## 上线与分发

单个 HTML 文件，不需要构建、不需要服务器：

- **GitHub Pages / Gitee Pages** — 把文件改名为 `index.html` 推上去，开 Pages 即可访问。
- **itch.io** — 打包成 zip 上传，勾选 "This file will be played in the browser"，入口文件设为 `index.html`。
- **Netlify / Vercel** — 直接把文件夹拖进去。
- **直接发文件** — 微信、网盘发 HTML 给对方，手机浏览器也能打开。

## 改它

HTML 没有压缩，直接用文本编辑器打开就能改：

- `<script>` 开头的 `T` 对象是全部游戏表格（世界、超能力、掩护身份、据点、关键人物、目标、关系、隐藏情感、情绪、话题引子、日常事件、超能力事件）。想改译法或做自己的变体版，改这里。
- `PAPERS` 数组是信纸主题：底色、字色、强调色、横线/方格、装饰，加一项就多一种信纸。
- `<style>` 里 `:root` 的颜色变量控制整体配色。
